Haya Drivers: transactional emails

One template for every email the server sends (generateProfessionalEmail.tsx), shown across the moments that matter to a driver and a client. It drops the solid blue header band for the same quiet structure Heed uses: logo on the canvas, a white card with a 1px border, and a 4px stripe that carries the meaning of the email (blue for routine, green for good news, amber when the driver has to act, red when something failed). Copy is taken from the existing services in src/utils/services/emails/, lightly tightened where noted. Nothing in src/ has changed yet.

  • Blocks the template would gain: a code block for OTPs, a details table (already supported via additionalDetails), an amount hero for money, a steps list, a document list for rejections, a callout in four tones and a trust score row.
  • Every amount is formatted from minor units at send time, so the email never shows a float.
  • General Sans renders here; in mail clients the stack falls back to the system font, which is why nothing depends on it.
